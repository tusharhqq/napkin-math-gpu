# NVIDIA B200 napkin math

This is a vendor-ceiling planning profile for one B200 SXM GPU. It is not yet a
calibrated Modal profile; achieved application throughput will be lower and
shape-dependent.

[General equations](README.md) · [H100](H100.md) · [B300](B300.md)

## Memorize these

| B200 SXM metric | Planning number |
| --- | ---: |
| HBM capacity | **180 GB** |
| HBM bandwidth ceiling | **8 TB/s** |
| Dense BF16/FP16 ceiling | **2.25 PFLOP/s** |
| Dense BF16/FP16 ridge point | **280 FLOP/byte** |
| NVLink GPU-to-GPU ceiling | **1.8 TB/s** |

Capacity, HBM bandwidth, and NVLink are hardware ceilings. The compute value is
derived from NVIDIA's eight-GPU HGX B200 table: 36 PFLOP/s BF16/FP16 with
sparsity, divided by two for dense math and by eight GPUs.

## Dense roofline ceilings

| Precision | Per-GPU compute | Ridge at 8 TB/s |
| --- | ---: | ---: |
| FP4 | 9.0 PFLOP/s | 1,125 FLOP/byte |
| FP8/FP6 | 4.5 PFLOP/s | 563 FLOP/byte |
| BF16/FP16 | 2.25 PFLOP/s | 281 FLOP/byte |
| TF32 | 1.125 PFLOP/s | 141 FLOP/byte |
| FP32 | 75 TFLOP/s | 9 FLOP/byte |

The FP4 row uses NVIDIA's explicitly published dense system figure. For the
FP8/FP6, BF16/FP16, and TF32 rows, NVIDIA publishes sparse figures and states
that dense throughput is half. These ceilings assume Tensor Core-compatible
operations where applicable.

## Quick BF16 estimate

```text
memory time  = HBM bytes / 8 TB/s
compute time = BF16 FLOPs / 2.25 PFLOP/s
device floor = max(memory time, compute time)
```

For 1 TB of HBM traffic and 2 PFLOPs of BF16 work:

```text
intensity = 2,000 FLOP/byte               → compute-bound
memory    = 1 TB / 8 TB/s       = 0.125 s
compute   = 2 PFLOP / 2.25 PFLOP/s ≈ 0.89 s
```

The roofline floor is about **0.9 seconds**. Real time will be higher unless the
kernel sustains near-peak Tensor Core throughput.

## Modal request and live identity

Use `gpu="B200"` for B200. `gpu="B200+"` explicitly allows either B200 or B300
and therefore must not label a canonical B200 benchmark. A live Modal allocation
on 2026-08-09 reported:

```text
NVIDIA B200, 183359 MiB, compute capability 10.0
```

Host-transfer speed, launch latency, achieved HBM bandwidth, and achieved GEMM
throughput are intentionally absent: they need a pinned full calibration and
must not be copied from H100.
