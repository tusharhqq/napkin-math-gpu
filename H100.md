# NVIDIA H100 napkin math

This is the practical profile. Its rounded working numbers come from the
checked-in full Modal calibration, not from the vendor peak table.

[General equations](README.md) · [Raw report](results/h100-sxm.md) ·
[Raw JSON](results/h100-sxm.json)

## Memorize these

| H100 SXM path | Napkin number |
| --- | ---: |
| Usable HBM capacity | **80 GB** |
| Tiny kernel | **5 μs** |
| CPU ↔ GPU | **50 GB/s** |
| HBM | **3 TB/s** |
| Dense BF16 compute | **700 TFLOP/s** |
| Dense BF16 ridge point | **240 FLOP/byte** |
| Pinned CPU RAM copy | **70 GB/s** |
| GPU ↔ GPU | **400 GB/s** |

These are deliberately rounded. The source profile was captured on two
Modal H100 SXM GPUs with PyTorch 2.8.0, CUDA 12.8, and driver 580.95.05. It
measured 4.66 μs, 55 GB/s host transfers, 3,000 GB/s HBM copy bandwidth,
717 TFLOP/s BF16 GEMM, and 393 GB/s for the slower direction of a direct peer
copy.

## Use them

```text
launch time   = kernels × 5 μs
transfer time = CPU↔GPU bytes / 50 GB/s
memory time   = HBM bytes / 3 TB/s
compute time  = BF16 FLOPs / 700 TFLOP/s
device time   = max(memory time, compute time)
rough time    = transfer time + device time + launch time
```

Below 240 FLOP/byte is probably memory-bound; above it is probably
compute-bound for dense BF16 work that resembles a large library GEMM.

## Worked estimate

A BF16 workload performs 200 TFLOPs, moves 1 TB through HBM, uploads 2 GB, and
launches 20 kernels:

```text
intensity = 200 TFLOP / 1 TB = 200 FLOP/byte  → memory-bound
compute   = 200 TFLOP / 700 TFLOP/s           ≈ 0.29 s
memory    = 1 TB / 3 TB/s                     ≈ 0.33 s
upload    = 2 GB / 50 GB/s                    = 0.04 s
launches  = 20 × 5 μs                         ≈ 0 s at this scale
total                                           ≈ 0.37 s
```

Rough answer: **about 0.4 seconds, slightly memory-bound**.

## Measured versus theoretical

| Metric | Measured calibration | NVIDIA H100 SXM ceiling |
| --- | ---: | ---: |
| HBM bandwidth | 3.00 TB/s | 3.35 TB/s |
| Dense BF16 | 717 TFLOP/s | 989.5 TFLOP/s |
| Dense BF16 ridge | 239 FLOP/byte | 295 FLOP/byte |

NVIDIA publishes 1,979 BF16 TFLOP/s **with sparsity**. The dense ceiling shown
here is half of that value. Do not mix the sparse headline with dense workload
FLOP counts.

## Modal request

Use `gpu="H100!"` for an exact H100. Modal may automatically upgrade
`gpu="H100"` to H200, which is useful for ordinary work but invalidates an H100
benchmark label. Modal states that its H100 fleet is the SXM variant.

Sources: [Modal GPU guide](https://modal.com/docs/guide/gpu) and
[NVIDIA H100 specifications](https://www.nvidia.com/en-us/data-center/h100/).
